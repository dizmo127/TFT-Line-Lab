# TFT Line Lab

Personal iPad-first TFT opener, comp, line-builder, and econ-guide PWA.

## GitHub Pages
Publish from the `main` branch, repository root (`/`).

Once enabled, the site URL is expected to be:
`https://dizmo127.github.io/TFT-Line-Lab/`

Open it in Safari on iPad, then Share → Add to Home Screen.

## Updates
Changes committed to `main` are published by GitHub Pages. The service worker keeps the app usable offline after it has been opened once.
